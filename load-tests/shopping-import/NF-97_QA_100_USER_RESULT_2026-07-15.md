## 판정

- 100명 동시성 조건에서 비동기 접수 100건을 429와 timeout 없이 수용했다.
- 서버는 OOM이나 재시작 없이 완료했으며 메모리·디스크 여유는 충분했다.
- 전체 완료 p95가 약 132초로 길고 CPU가 95%까지 올라 일반 API 트래픽을 위한 여유는 크지 않다.
- 올리브영 실패 15건은 부하 용량 문제와 분리해 수집 호환성 문제로 확인해야 한다.
- 현재 서버는 100건 일시 유입을 버티지만, 결과 완료시간 목표가 2분 미만이거나 같은 시간에 일반 API 트래픽이 크다면 CPU/worker 구조의 추가 검증이 필요하다.
